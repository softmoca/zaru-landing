# 자루 랜딩 — 내용·문구 전문

> 이 문서의 문구를 **그대로** 랜딩에 사용합니다. 임의로 바꾸거나 새로 짓지 마세요.
> 톤: 지적하지 않는다. 잔소리 아닌 "대신 기억해주는" 포근한 친구.

## 섹션 순서

```
[1] 히어로            — 한 줄 후킹 + 사전예약 버튼
[2] 공감/문제         — "마지막으로 ○○ 청소한 게 언제였나요?"
[2.5] 마퀴 띠         — 쉼표 역할
[3] 문제 3카드        — 기준X / 내답X / 부채
[4] 자루 소개          — 이름 의미 + 정의
[5] 핵심 기능 3축      — ★ 스티키 저니 (메인 이벤트)
[6] 시나리오          — 알림 3비트
[7] 다시 루프         — ★ 원형 시퀀스 (재방문 강조)
[8] 사전예약 CTA      — 최종 전환
[9] 푸터
```

## [1] 히어로

```
(아이브로우)  자취 루틴 관리 · 자루

(H1)  놓치는 자취 살림,
      자루가 대신 기억해요

(서브, 품목 로테이션)  화장실 · 배수구 · 이불 · 에어컨 필터 —
       언제 했는지 기억 안 나는 것들, 자루가 챙겨드릴게요.

(품목 칩 3개)  #화장실  #배수구  #이불

(버튼)  사전예약하고 먼저 받아보기
(안심)  아직 만드는 중이에요. 출시되면 가장 먼저 알려드릴게요.
```

## [2] 공감/문제

```
(질문, 형광 하이라이트)  마지막으로 배수구를 청소한 게 언제였나요?

(서브)  이불은 언제 빨았는지, 에어컨 필터는 언제 갈았는지
       — 바로 떠오르시나요?

(말풍선 1)  "이불은 언제 빨았지?
           배수구 냄새는 어떻게 없애지?"
(말풍선 2)  정신없이 지내다, 문득 더러워진 방을 발견합니다.
           일주일에도 몇 번씩 드는 생각.

(강조 문장)  한 번 밀린 집안일은,
            우리를 계속 괴롭게 만듭니다.
```

## [2.5] 마퀴 띠


## [3] 문제 3카드

```
(섹션 타이틀)  자취 살림은, 유지가 어렵다

  01  기준도 주기도 없다
      욕실은 몇 주마다, 침구는 언제 빨아야 할까요?
      기준이 없으면 자꾸만 미루게 됩니다.

  02  정보는 많은데 '내 답'이 없다
      검색 결과는 넘칩니다. 수많은 용품과 유행하는 업체까지 —
      청소보다 제품 찾는 시간이 여가를 잡아먹습니다.

  03  놓치면 부채처럼 쌓인다
      바닥 쓸기, 빨래, 쓰레기 처리… 하나둘 놓치면
      끝없이 쌓여, 아까운 주말 내내 청소만 하게 됩니다.

(하단 띠, 화살표 순차 점등)  미룬다 → 주기 감각이 흐려진다 → 결국 포기한다
```

## [4] 자루 소개

```
(아이브로우)  자취 + 루틴 = 자루

(H2)  자루

(서브 강조)  놓친 주기는, 자루가 대신 기억해요.

(설명)  밀려가는 자취 살림을 제때 비워내고,
       정돈된 생활과 내 시간을 다시 누리게 하는 것 —
       이것이 자루의 목표입니다.
```

## [5] 핵심 기능 3축 (★ 스티키 저니)

> 프로토타입의 하단 탭 3개(**홈 / 살림정보 / 마이**)를 그대로 따른다.
> 예전 "자루 픽"과 "자취 정보 조립소"는 각각 독립 축이 아니라
> **살림정보 안의 세그먼트**(살림템 / 조립소)가 됐다.
> 세그먼트 4개: `살림템 | 조립소 | 꿀팁 | Q&A`

```
(섹션 타이틀)  자루의 세 가지 축

  01  오늘 챙길 일                                    [홈]
      욕실 · 세탁 · 쓰레기 같은 카테고리마다 마지막으로 언제 했는지,
      다음은 언제인지 보여드려요. 주기가 돌아오면 자루가 알림으로
      불러드립니다. 주기 없이 적어만 두고 싶은 건 '적어두기'에
      따로 모아둬요.

  02  살림에 필요한 건 여기 다                         [살림정보]
      용품과 대행 서비스를 나란히 놓고 고르는 살림템,
      흩어진 자취 정보를 한 장으로 모은 조립소.
      먼저 겪어본 사람들의 꿀팁과 Q&A까지 한곳에 있습니다.

  03  쌓이는 기록                                     [마이]
      완료한 집안일과 저장해 둔 살림템 · 꿀팁이 차곡차곡 쌓입니다.
      이번 달 몇 번이나 비워냈는지, 가끔 돌아보세요.

(하단 흐름)  앱을 연다 → 오늘 챙길 일을 본다 → 완료를 기록한다 → 필요할 때 답을 찾는다
```

> 하단 흐름은 축 목록이 아니라 **시간 순서**라 3축과 1:1로 맞지 않아도 된다.
> 앞의 셋은 홈, 마지막이 살림정보.

### 용어 (프로토타입 기준)

| 지금 이름 | 옛 이름 | 위치 |
|---|---|---|
| 살림템 | 자루 픽 | 살림정보 세그먼트 |
| 조립소 | 자취 정보 조립소 | 살림정보 세그먼트 |
| 적어두기 | (신규) | 홈 최상단, 접힌 상태. 주기 없이 메모만 하는 카테고리(지출사항, 장보기) |
| 관리 팁 | (신규) | 홈 카드에서 열리는 바텀시트. 그 카테고리의 조립 카드 + 꿀팁 + 전체 보기 |

- **적어두기**는 01 본문에 한 줄로 들어가 있다.
- **관리 팁**은 [6] 시나리오 뒤쪽 블록에서 캡처 2장으로 보여준다.

## [6] 시나리오 (알림 3비트 + 관리 팁)

```
(아이브로우)  시나리오 · 어느 하루

(H2)  알림 하나로
      오늘 챙길 일이 정리된다

(3비트)
  ① 알림 도착 — "이번 주엔 욕실만 챙겨도 좋아요"
  ② 앱을 열면 오늘 할 일이 정렬돼 있고
  ③ 완료를 누르면, 다음 주기가 자동으로 잡힙니다

(말풍선)  지적이 아닌, 기억을 돕는 리마인드 톤.
```

### 관리 팁 (3비트 아래, 구분선으로 나눔)

```
(아이브로우)  관리 팁

(H3)  어떻게 하는지 모를 땐,
      카드에서 바로

(설명)  카드의 관리 팁을 누르면 그 자리에서 바텀시트가 올라옵니다.
       이 카테고리에 맞게 정리된 답과, 먼저 겪어본 사람들의 꿀팁이
       함께 있어요. 더 보고 싶으면 조립소로 이어집니다.

(캡처 2장 + 화살표)
  02-tips.png      캡션: 카드에서 관리 팁 열기
  04-assembly.png  캡션: 정리된 답으로 이어지기
```

> "몰라서 못 하는 것"을 그 자리에서 푸는 흐름이라 하루 시나리오의 연장선에 둔다.
> 1차 아이템이던 정보 조립이 루틴 안에서 어떻게 살아남는지를 보여주는 자리이기도 하다.

## [7] 다시 루프 (★ 원형 시퀀스, 재방문 = 차별점)

```
(아이브로우)  다시 루프

(H2)  다음 주기가 오면,
      다시 자루로

(설명)  완료가 쌓이고 관리 시점이 돌아오면 자루가 다시 알림을 보냅니다.
       놓쳤던 것도, 잘 챙긴 것도 — 주기에 맞춰 다시 이어집니다.

(원형 시퀀스)  알림 → 완료 → 다음 주기 → 다시 알림 (원이 닫힘)
(카운트업)  이번 달 완료 12회
```
