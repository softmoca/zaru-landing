### 타이포
- 한국어 고딕 산세리프 (Pretendard 권장). 굵기 2단계(굵게=제목 / 보통=본문).
- 세리프·손글씨·장식체 금지.

## 2. 스크롤 인터랙션 스펙 (RingOut 문법 이식)

### 전역
- 상단 2~3px 스크롤 프로그레스 바 (`#667A3E`)
- 헤더: `scrollY > 20`에서 높이 축소 + 배경 블러
- 공통 `.reveal`: `threshold 0.12`, `rootMargin 0 0 -7% 0`, `opacity 0→1 / translateY 28px→0`, `0.7~0.8s cubic-bezier(0.2,0.8,0.2,1)`
- **`transform` + `opacity`만 사용** (성능)
- `prefers-reduced-motion: reduce` → 전환 끄고 처음부터 보이게

### 섹션별 (P0=필수, P1=여유되면)

| 섹션 | 인터랙션 | 우선 |
|---|---|---|
| [1] 히어로 | `--zaru-progress` 0→1 패럴랙스: 폰 목업 `translateY(progress*30px)`, 좌측 카드 `-22px`, 우측 카드 `+25px`. 서브 품목만 2.4s 간격 슬라이드업 교체(화장실→배수구→이불→에어컨필터) — 실제 구현은 CONTENT 문구를 그대로 둔 채 **강조만 2.4s 간격으로 옮긴다**(교체하면 나머지 품목이 사라짐). 품목 칩 3개 배경·회전각(-1.5deg/+1deg) | P0 |
| [2] 공감 | 굵은 부분에만 형광 밑줄 `scaleX 0→1`, 0.55s, is-visible 시점. **페이지 전체에서 여기 1회만**. 말풍선 2개 120ms 시차 | P0 |
| [2.5] 마퀴 | 무한 루프, `rotate(-1.2deg)`, 다크(딥포레스트) 배경 + 올리브 점. 20초 루프 | P1 |

| [4] 소개 | 진입 시 배경 크림→화이트 0.8s 전환. 인터랙션 일부러 죽여 [5] 완충 | P1 |

### 스티키 저니 3스텝 목업 내용
- `1` 오늘 챙길 일 (홈) → `01-home.png` — 적어두기 접힘 + 루틴 카드
- `2` 살림에 필요한 건 여기 다 (살림정보) → `03-supplies.png` — 살림템 세그먼트
- `3` 쌓이는 기록 (마이) → `05-my.png` — 완료 기록 + 저장한 것들

스텝과 화면은 `StickyJourney.tsx` 의 같은 `STEPS` 배열에서 렌더한다.
스텝을 늘리거나 줄일 땐 배열만 고치면 되고, `data-step` 을 따로 맞출 필요가 없다.
(단, `styles.css` 의 `[data-active-step="n"]` 짝은 개수만큼 있어야 한다)

### 모바일 (≤768px)
- 스티키 완전 해제: `position:relative`, 비주얼 `clamp(500px, 68svh, 620px)`, 스텝 `opacity:1` 고정, `min-height:88svh` → `padding:64px 0` + 상단 구분선
- [7] 원형 진행 → 세로 타임라인으로 변경
- (스티키를 모바일에서 억지 유지하면 100svh가 주소창 때문에 깨짐)

### 구현 순서
```
[5] 스티키 저니 → [1] 히어로 패럴랙스 → [7] 루프 → 나머지 reveal
([5]를 먼저 만들어야 페이지 골격 높이가 정해짐. P0만 하루, 전체 2~3일)
```

- 원본은 1170×2532 (DPR 3). `assets-src/mockups/` 에 보관 — **배포에 포함되지 않는다.**
- `public/mockups/` 에는 폭 **780px** 로 줄인 것만 둔다 (표시 폭의 약 3배). 합계 4.4MB → 2.2MB.
  ```
  sips --resampleWidth 780 assets-src/mockups/01-home.png --out public/mockups/01-home.png
  ```
- `PhoneFrame` 이 `src` / `alt` / `priority` 를 받는다.
  - `width`/`height` 를 명시해 이미지 도착 전에도 자리를 잡는다 (CLS 방지)
  - **히어로만 `eager`**, 나머지는 `loading="lazy"` + `decoding="async"`
  - `.phone__screen` 의 `aspect-ratio` 는 캡처 원본 비율 `1170 / 2532`
- `alt` 는 화면 내용을 설명하는 한국어로. 목록은 `src/components/mockups/mockups.ts` 한 곳에 모아둔다.
- 화면이 바뀌면 `assets-src` 의 원본을 갈아끼운 뒤 위 명령으로 다시 줄여 넣는다.
