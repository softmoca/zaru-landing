# 자취선배 팀 빌딩 랜딩

처음 방을 보는 날부터 떠나는 날까지, 지금 해야 할 일을 알려주는 **첫 자취 생활 내비게이터**의 팀 빌딩용 랜딩페이지입니다.

> 이 작업은 `codex/team-building-landing` 브랜치와 Vercel Preview에서만 진행합니다.
> 기존 자루 랜딩은 `main` 브랜치와 `https://zaru-landing.vercel.app/`에 그대로 보존합니다.

## 목적

- 첫 자취생의 뾰족한 문제와 서비스 방향을 우아한테크코스 크루에게 짧게 공유
- 사전예약이 아니라 팀 빌딩 대화를 시작
- 첫 번째 핵심 검증 대상인 **집 보러 가기**의 사용자 행동과 성공 기준 설명
- 가설 → 실제 사용자 → 행동 관찰 → 판단 → 개발의 검증 방식 공유

## 서비스 정의

> 처음 방을 보는 날부터 떠나는 날까지, 지금 해야 할 일을 알려주는 자취 생활 내비게이터

```
알려준다 → 확인한다 → 기록한다 → 다음 행동으로 이어진다
```

초기 범위는 지원금 확인, 집 보러 가기, 입주 준비입니다. 지원금은 독립 모듈로 다루며, 첫 번째 핵심 검증은 집 보러 가기입니다.

## 페이지 구성

1. 헤더
2. 히어로
3. 첫 자취의 핵심 문제
4. 자취선배 소개
5. 처음 시작할 세 가지 순간
6. 집 보러 가기 사용자 시나리오
7. 기록이 다음 순간으로 이어지는 구조
8. 전체 자취 타임라인
9. 검증 계획
10. 팀 빌딩 CTA
11. 푸터

## 기술 스택

- Vite + React 18 + TypeScript
- 순수 CSS — 새 UI 라이브러리 없음
- IntersectionObserver 기반 reveal과 스크롤 진행률
- `prefers-reduced-motion` 대응
- Supabase 이벤트 계측 · Vercel 배포

## 실행과 검증

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

확인 항목:

- 데스크톱·모바일 레이아웃
- 스크롤 reveal, 상단 진행 바, 헤더 compact 전환
- reduced motion에서 모든 콘텐츠가 즉시 노출되는지
- 콘솔 오류가 없는지

## 계측

| 이벤트 | 시점 |
|---|---|
| `view` | 페이지 진입 |
| `depth` | 스크롤 25/50/75/100% |
| `step_view` | 세 가지 순간 도달 |

사전예약 이메일 폼과 `notify`, `kakao_click` 이벤트는 현재 방향에서 제거했습니다.

## 이전 방향: 자루 루틴 서비스

이 저장소의 `main`은 자취 청소·관리 주기를 잡아주고 알림으로 재방문을 유도하던 **자루 루틴 서비스 사전예약 랜딩**입니다. 실제 앱 캡처, 이메일 사전예약, 카카오톡 알림 CTA를 사용했습니다.

이전 방향은 삭제하거나 운영 페이지에서 교체하지 않습니다. 구체적인 검증 결과와 피벗 배경은 `docs/CONTEXT.md`에 남겨두었습니다.
