# 자취선배 계약 전 주거지원 지도 프로토타입

첫 월세 계약을 앞둔 사용자가 자신의 조건과 실제 후보 집의 조건을 함께
확인해, 계약 전에 놓친 월세·보증금·이사비 지원과 중개인 질문을 발견하는 모바일
프로토타입입니다.

> 이 작업은 `codex/support-check-prototype` 브랜치와 Vercel Preview에서만 진행합니다.
> 기존 자루 랜딩은 `main` 브랜치와 `https://zaru-landing.vercel.app/`에 그대로 보존합니다.
> 기준 팀 빌딩 랜딩 `codex/team-building-landing`과 기존 Preview도 변경하지 않습니다.

## 이번 검증

- 실제 매물 A에서 프로토타입 사용 전후의 질문·판단 차이 확인
- 실제 매물 B에서 안내 없이 프로토타입을 다시 사용하는지 확인
- 사용 전 지원제도 인지 수준과 사용 후 새로 발견한 지원·질문·행동의 차이 확인
- 지원 목록 열람이 아니라 공식 출처 확인, 질문 복사, 후보 판단 기록을 관찰
- 자격 확정 없이 계약 전에 확인할 조건을 발견하게 하는 흐름 검증

## 현재 서비스 정의

> 첫 월세 계약 전에 눈앞의 월세뿐 아니라 전입신고·주택 유형·계약 증빙 때문에
> 달라질 수 있는 주거지원과 다음 행동을 함께 확인한다.

```
사용 전 인지 수준 → 나의 조건 → 실제 후보 집 → 지원 후보 → 질문·증빙 → 판단
```

현재 프로토타입은 2026년 공개된 전국 청년월세지원, 서울시 청년월세지원,
서울시 청년 임차보증금 이자지원, 서울시 중개보수·이사비 지원, 성남시
취업청년 주거지원 기준을 참고합니다. 모집 상태와 확인할 행동을 구분해서
보여주며, 지원 대상 여부를 확정하거나 신청을 대행하지 않습니다.

고시원은 일괄적으로 지원 불가로 판정하지 않습니다. 전입신고 가능 여부,
입실확인서 또는 임대차계약서, 월세 납부 증빙을 지원별로 다시 확인하도록
안내합니다.

## 프로토타입 흐름

1. 검증 범위와 면책 안내
2. 사용 전 청년월세지원 이해 단계와 이미 알고 있던 제도·지식 중복 선택
3. 실제 후보 집의 지역·주거 형태·전입·증빙 조건 입력
4. 지역별 지원 후보와 모집 상태 확인
5. 계약 전 질문·남길 증빙·후보 판단 기록
6. 개인 조건은 유지하고 두 번째 후보 집에서 자발적 재사용 확인

## 기술 스택

- Vite + React 18 + TypeScript
- 순수 CSS — 새 UI 라이브러리 없음
- React 상태 기반 4단계 입력 흐름
- `prefers-reduced-motion` 대응
- Supabase 이벤트 계측 · Vercel 배포

## 실행과 검증

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

확인 항목:

- 데스크톱·모바일 레이아웃
- 개인 조건·매물 조건 입력과 결과 분기
- 질문 복사, 판단 기록, 다른 집 확인
- reduced motion에서 모든 콘텐츠가 즉시 노출되는지
- 콘솔 오류가 없는지

## 계측

| 이벤트 | 시점 |
|---|---|
| `view` | 프로토타입 진입 |
| `prototype_start` | 시작 버튼 클릭 |
| `profile_completed` | 개인 조건 완료 |
| `listing_completed` | 후보 집 조건 완료 |
| `result_viewed` | 확인 결과 노출 |
| `question_copied` | 중개인 질문 복사 |
| `research_record_copied` | 익명 검증 기록 복사 |
| `decision_saved` | 후보 판단 기록 |
| `official_source_clicked` | 공식 출처 확인 |
| `second_listing_started` | 다른 집 확인 시작 |

이벤트에는 연령·소득·보증금·월세 등 입력값을 저장하지 않습니다. Vercel에
Supabase 환경변수가 없으면 이벤트는 브라우저 콘솔에만 남습니다. 이 경우 결과
화면의 `익명 검증 기록 복사하기`로 원본 오픈채팅에 기록을 남깁니다. URL의
`?participant=P01&src=openchat`처럼 익명 참가자 번호와 모집 채널만 구분할 수
있습니다.
