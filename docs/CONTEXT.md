# 자루 — 프로젝트 배경 & 의사결정 히스토리

> Claude Code가 "왜 이렇게 만드는지" 이해하기 위한 배경 문서. 코드에 직접 반영할 스펙은 CONTENT/DESIGN 참고.

## 프로젝트 정체
- 우아한테크코스(우테코) 8기 백엔드 크루 모카(최영철)의 **레벨3** 프로젝트
- 레벨3 본질: 유저가 있는 서비스를 만들며 "가설→계측→관찰→결정" 사이클을 익히는 것. 서비스 성공이 아니라 **판단력**과 **재방문(실사용)** 이 핵심.

## 피벗 히스토리
### 1차: "자취 정보 조립소" (검증 완료 → 피벗)
- 흩어진 자취 정보를 한 장으로 조립해 제공
- 가설: "사람들은 스스로 검색·판단하는 대신 조립된 정보를 받아들이는가"
- **결과: 광고 냉담 표본 카드 펼침률 4%(기준 30%), 즉시이탈 58%, 형식 수용 기각에 가까움**
- 근본 문제: 문제 생겼을 때만 오는 "문제 해결형" → **재방문이 약함**
- 페인·무지(C축)·소재 CTR(2.58%)은 살아있음 → 문제는 진짜, **형식이 틀림**

### 2차: "자루" (현재)
- 청소·관리 **주기를 잡아주고 알림으로 재방문**시키는 루틴 앱
- 문제·타겟 유지, 해결 형식만 피벗 (정보 조립 → 루틴 관리)
- 근거: 구글폼 32명 Q8에서 **사용자가 먼저 청소·관리 정리를 요청** (세탁기 청소법, 곰팡이·물때, 필터, 습도·냄새 관리)

### 프로토타입 완성 후 구조 변경
랜딩은 프로토타입보다 먼저 만들어졌다. 이후 프로토타입이 나오면서 구조가 정리됐고,
**검증하려는 가설과 톤은 그대로**지만 화면 구성이 바뀌었다.

- **4탭 → 3탭** (`홈 / 살림정보 / 마이`). "자루 픽"과 "자취 정보 조립소"가 각각
  독립 축이 아니라 **살림정보 안의 세그먼트**가 됐다.
  세그먼트 4개: `살림템 | 조립소 | 꿀팁 | Q&A`
- **이름 변경**: 자루 픽 → **살림템** / 자취 정보 조립소 → **조립소**
- **신규 "적어두기"**: 주기 없이 메모만 하는 카테고리(지출사항, 장보기).
  홈 최상단에 접힌 상태로 있다.
- **신규 "관리 팁"**: 홈 카드에서 열리는 바텀시트. 그 카테고리의 조립 카드 +
  꿀팁 + 전체 보기가 한 번에 나온다.

1차 아이템이었던 정보 조립이 독립 축에서 세그먼트 하나로 내려간 것은,
"형식이 틀렸다"는 1차 검증 결과와 방향이 같다. 페인은 살아 있으니 기능은 남기되
서비스의 중심은 주기·알림(재방문)에 둔다.

랜딩의 [5] 스티키 저니도 이 3탭 구조를 그대로 따라간다. 목업은 CSS로 그린
플레이스홀더에서 **실제 앱 캡처**로 교체됐다.

## 검증 데이터 (요약)
- 구글폼 32명: 그냥 포기 8명, 지원금 순차수급 몰랐다 22명, 청소·관리 요청 다수
- Supabase 펼침률: 광고 4% / 구글폼 27% / 직접 19%
- 메타 광고: 지출 16,047원, CTR 2.58%, 잔액 약 19,000원 남음(재사용 가능)

## 이 랜딩의 검증 목표
- 다음 가설: **"청소·관리 주기를 잡아주고 알림으로 부르면 꾸준히 돌아오는가"**
- 가장 위험한 가정: "알림 받으려고 계속 앱을 여는가(재방문하는가)"
- 랜딩은 그 전 단계 검증: **"이런 서비스 나오면 쓸래?" → 사전예약률**로 수요 측정

## 팀 (참고)
- 레벨3 팀: 백엔드 3(모카) + 프론트 2, **React Native**로 iOS+안드 앱 예정 (타겟 아이폰 60%)
- 이 랜딩(웹)은 앱 출시 전 수요 검증 + 획득 창구

## 계측 설계
- Supabase events: `view` / `depth`(스크롤 지점) / `notify`(이메일 제출) / `kakao_click` / 스티키 스텝 도달
- `?src=` 파라미터로 유입 분리: ig(광고) / form(구글폼) / euta / openchat / woowa / friend
- 판정은 Supabase, 유입은 메타, 총량은 GA4, 이탈원인은 Clarity (역할 분담)

## 브랜드 철학
- 비누(파랑, 깨끗하게 관리)와 구분되는 **자루(올리브그린, 포근하게 정리)**
- "따뜻한 크림 공간에 올리브 자루가 할 일을 담아준다"
- 톤: 지적·잔소리 아님. "대신 기억해주는" 친구.
