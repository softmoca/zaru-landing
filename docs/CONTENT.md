# 자루 랜딩 — 내용·문구 전문

> 이 문서의 문구를 **그대로** 랜딩에 사용합니다. 임의로 바꾸거나 새로 짓지 마세요.
> 톤: 지적하지 않는다. 잔소리 아닌 "대신 기억해주는" 포근한 친구.

## 섹션 순서

```
[1] 히어로            — 한 줄 후킹 + 사전예약 버튼
[2] 공감/문제         — "마지막으로 ○○ 청소한 게 언제였나요?"
[2.5] 마퀴 띠         — 쉼표 역할
[3] 문제 3카드        — 기준X / 내답X / 부채
[4] 자루 소개          — 이름 의미 + 정의
[5] 핵심 기능 4축      — ★ 스티키 저니 (메인 이벤트)
[6] 시나리오          — 알림 3비트
[7] 다시 루프         — ★ 원형 시퀀스 (재방문 강조)
[8] 사전예약 CTA      — 최종 전환
[9] 푸터
```

## [1] 히어로

```
(아이브로우)  자취 루틴 관리 · 자루

(H1)  놓치는 자취 살림,
      자루가 대신 기억해요

(서브, 품목 로테이션)  화장실 · 배수구 · 이불 · 에어컨 필터 —
       언제 했는지 기억 안 나는 것들, 자루가 챙겨드릴게요.

(품목 칩 3개)  #화장실  #배수구  #이불

(버튼)  사전예약하고 먼저 받아보기
(안심)  아직 만드는 중이에요. 출시되면 가장 먼저 알려드릴게요.
```

## [2] 공감/문제

```
(질문, 형광 하이라이트)  마지막으로 배수구를 청소한 게 언제였나요?

(서브)  이불은 언제 빨았는지, 에어컨 필터는 언제 갈았는지
       — 바로 떠오르시나요?

(말풍선 1)  "이불은 언제 빨았지?
           배수구 냄새는 어떻게 없애지?"
(말풍선 2)  정신없이 지내다, 문득 더러워진 방을 발견합니다.
           일주일에도 몇 번씩 드는 생각.

(강조 문장)  한 번 밀린 집안일은,
            우리를 계속 괴롭게 만듭니다.
```

## [2.5] 마퀴 띠

```
잊어도 괜찮아요 · 자루가 기억하니까 · 잊어도 괜찮아요 · 자루가 기억하니까 ·
```
(무한 루프, rotate -1.2deg, 딥 포레스트 배경 + 올리브 점)

## [3] 문제 3카드

```
(섹션 타이틀)  자취 살림은, 유지가 어렵다

  01  기준도 주기도 없다
      욕실은 몇 주마다, 침구는 언제 빨아야 할까요?
      기준이 없으면 자꾸만 미루게 됩니다.

  02  정보는 많은데 '내 답'이 없다
      검색 결과는 넘칩니다. 수많은 용품과 유행하는 업체까지 —
      청소보다 제품 찾는 시간이 여가를 잡아먹습니다.

  03  놓치면 부채처럼 쌓인다
      바닥 쓸기, 빨래, 쓰레기 처리… 하나둘 놓치면
      끝없이 쌓여, 아까운 주말 내내 청소만 하게 됩니다.

(하단 띠, 화살표 순차 점등)  미룬다 → 주기 감각이 흐려진다 → 결국 포기한다
```

## [4] 자루 소개

```
(아이브로우)  자취 + 루틴 = 자루

(H2)  자루

(서브 강조)  놓친 주기는, 자루가 대신 기억해요.

(설명)  밀려가는 자취 살림을 제때 비워내고,
       정돈된 생활과 내 시간을 다시 누리게 하는 것 —
       이것이 자루의 목표입니다.
```

## [5] 핵심 기능 4축 (★ 스티키 저니)

> 순서 주의: 정보조립소는 **03(덤 위치)**. 목업 대신 정적 카드로 톤 한 단계 낮춤.

```
(섹션 타이틀)  자루의 네 가지 축

  01  홈케어 주기 관리
      욕실 · 세탁 · 쓰레기 같은 카테고리로
      마지막 완료일과 다음 관리 시점을 확인합니다.
      주기가 돌아오면 자루가 알림으로 알려드려요.

  02  자루 픽
      상황과 소재에 맞는 용품과 서비스를 한곳에서 비교합니다.
      직접 할지, 용품을 살지, 서비스에 맡길지 —
      선택의 폭이 넓어집니다.

  03  자취 정보 조립소
      물때는 어떻게 없애지? 지원금은 어디까지 받지?
      흩어진 자취 정보를 한 장으로 조립해 드립니다.
      검색 대신, 정리된 답을 확인하세요.

  04  마이
      도움이 된 팁과 완료한 집안일 기록을 저장하고,
      다음에 필요할 때 다시 꺼내봅니다.

(하단 흐름)  앱을 연다 → 오늘 챙길 일을 본다 → 완료를 기록한다 → 필요할 때 답을 찾는다
```

## [6] 시나리오 (알림 3비트)

```
(아이브로우)  시나리오 · 어느 하루

(H2)  알림 하나로
      오늘 챙길 일이 정리된다

(3비트)
  ① 알림 도착 — "이번 주엔 욕실만 챙겨도 좋아요"
  ② 앱을 열면 오늘 할 일이 정렬돼 있고
  ③ 완료를 누르면, 다음 주기가 자동으로 잡힙니다

(말풍선)  지적이 아닌, 기억을 돕는 리마인드 톤.
```

## [7] 다시 루프 (★ 원형 시퀀스, 재방문 = 차별점)

```
(아이브로우)  다시 루프

(H2)  다음 주기가 오면,
      다시 자루로

(설명)  완료가 쌓이고 관리 시점이 돌아오면 자루가 다시 알림을 보냅니다.
       놓쳤던 것도, 잘 챙긴 것도 — 주기에 맞춰 다시 이어집니다.

(원형 시퀀스)  알림 → 완료 → 다음 주기 → 다시 알림 (원이 닫힘)
(카운트업)  이번 달 완료 12회
```

## [8] 사전예약 CTA

```
(H2)  비우는 루틴, 누리는 당신

(서브)  자루는 아직 만드는 중이에요.
       먼저 받아보고 싶다면, 사전예약해 주세요.

(입력, 인라인)  이메일 주소
(버튼)  사전예약하기
(보조 버튼)  또는 카카오톡 채널로 알림 받기

(안심)  출시되면 가장 먼저 알려드릴게요. 스팸은 보내지 않아요.
```

## 넣지 말 것 (검증 오염 방지)

- 검증 데이터 노출 금지 ("32명이 원했어요" 같은 숫자 X — 반응 유도하면 순수 측정 불가)
- 과장·1등·완벽 표현 금지
- 가짜 후기 금지 (아직 사용자 없음)
- "만드는 중" 프레임 유지 (사전예약이 자연스러워짐)
