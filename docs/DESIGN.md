# 자루 랜딩 — 디자인 & 인터랙션 스펙

## 1. 컬러 시스템 (확정)

**메인 = `#667A3E` 올리브그린 · 기본 배경 = `#F8F3E8` 웜 크림**

| 용도 | 컬러 | HEX |
|---|---|---|
| 메인 브랜드 | 올리브그린 | `#667A3E` |
| 진한 배경·제목 | 딥 포레스트 | `#344126` |
| 기본 배경 | 웜 크림 | `#F8F3E8` |
| 보조 배경 | 내추럴 베이지 | `#E5D5B8` |
| 밝은 보조색 | 세이지그린 | `#A8B887` |
| 포인트 | 머스터드 옐로 | `#F3C85B` |
| 본문 글자 | 브라운 차콜 | `#36352F` |
| 경고·중요 | 소프트 코랄 | `#D8795F` |

**사용 비율**: 웜크림 55% · 올리브 25% · 딥포레스트 10% · 베이지 5% · 노랑·코랄 5%

> 초록으로 화면을 채우지 않는다. 크림 공간 위에서 올리브가 브랜드를 대표한다.
> RingOut의 주황이 하던 "활력"을 자루는 올리브가 "청결·신뢰·포근"으로 치환.

### 타이포
- 한국어 고딕 산세리프 (Pretendard 권장). 굵기 2단계(굵게=제목 / 보통=본문).
- 세리프·손글씨·장식체 금지.

## 2. 스크롤 인터랙션 스펙 (RingOut 문법 이식)

### 전역
- 상단 2~3px 스크롤 프로그레스 바 (`#667A3E`)
- 헤더: `scrollY > 20`에서 높이 축소 + 배경 블러
- 공통 `.reveal`: `threshold 0.12`, `rootMargin 0 0 -7% 0`, `opacity 0→1 / translateY 28px→0`, `0.7~0.8s cubic-bezier(0.2,0.8,0.2,1)`
- **`transform` + `opacity`만 사용** (성능)
- `prefers-reduced-motion: reduce` → 전환 끄고 처음부터 보이게

### 섹션별 (P0=필수, P1=여유되면)

| 섹션 | 인터랙션 | 우선 |
|---|---|---|
| [1] 히어로 | `--zaru-progress` 0→1 패럴랙스: 폰 목업 `translateY(progress*30px)`, 좌측 카드 `-22px`, 우측 카드 `+25px`. 서브 품목만 2.4s 간격 슬라이드업 교체(화장실→배수구→이불→에어컨필터). 품목 칩 3개 배경·회전각(-1.5deg/+1deg) | P0 |
| [2] 공감 | 굵은 부분에만 형광 밑줄 `scaleX 0→1`, 0.55s, is-visible 시점. **페이지 전체에서 여기 1회만**. 말풍선 2개 120ms 시차 | P0 |
| [2.5] 마퀴 | 무한 루프, `rotate(-1.2deg)`, 다크(딥포레스트) 배경 + 올리브 점. 20초 루프 | P1 |
| [3] 문제카드 | 3장 0/120/240ms 스태거 등장. 하단 화살표 좌→우 순차 점등, 마지막 "포기한다"만 회색 | P0 |
| [4] 소개 | 진입 시 배경 크림→화이트 0.8s 전환. 인터랙션 일부러 죽여 [5] 완충 | P1 |
| [5] 4축 | ★ **스티키 저니**: 좌측 앱 목업 `position:sticky; top:96px; height:calc(100svh-120px)`. 우측 4스텝 각 `min-height:88svh`. IntersectionObserver(`threshold:[0.25,0.45,0.65]`, `rootMargin:-25% 0px -35% 0px`) → 비주얼에 `data-active-step=1~4` → 목업 화면 교체. 비활성 `opacity:0.26; translateY(25px)`, 활성 `1; 0`, 0.5s. **03(정보조립소)은 목업 대신 정적 카드로 톤 한 단계 낮춤** | P0 |
| [6] 시나리오 | 가로 3칸 시퀀스(**스티키 재사용 금지**). 각 240ms 시차 리빌 + 사이 화살표 순차 점등 | P1 |
| [7] 다시루프 | ★ **원형 시퀀스**: 4뱃지(알림→완료→다음주기→다시알림) 원형 배치. 스크롤 진행률 0→1을 SVG `stroke-dashoffset`에 물려 원호 그리기. 0.25/0.5/0.75/1.0에서 뱃지 순차 점등, 마지막에 첫 뱃지로 이어져 원 닫힘. 옆 "이번 달 완료 12회" 숫자 카운트업(`threshold 0.55`) | P0 |
| [8][9] CTA·푸터 | 버튼 호버만. **모달 금지, 인라인 입력** | P0 |

### 스티키 저니 4스텝 목업 내용
- `1` 홈케어 주기 관리 → 카테고리 주기 리스트 화면
- `2` 자루 픽 → 용품·서비스 비교 카드 화면
- `3` 자취 정보 조립소 → **정적 정보 카드 1장** (톤 낮춤)
- `4` 마이 → 완료 기록 캘린더 (도장 찍히는 모션)

### 모바일 (≤768px)
- 스티키 완전 해제: `position:relative`, 비주얼 `clamp(500px, 68svh, 620px)`, 스텝 `opacity:1` 고정, `min-height:88svh` → `padding:64px 0` + 상단 구분선
- [7] 원형 진행 → 세로 타임라인으로 변경
- (스티키를 모바일에서 억지 유지하면 100svh가 주소창 때문에 깨짐)

### 구현 순서
```
[5] 스티키 저니 → [1] 히어로 패럴랙스 → [7] 루프 → 나머지 reveal
([5]를 먼저 만들어야 페이지 골격 높이가 정해짐. P0만 하루, 전체 2~3일)
```
